# CCTVMOS MAX Bot

Бот для MAX: обслуживание видеонаблюдения коммерческих объектов Москвы.

## Что делает
- Меню с inline-кнопками
- 55 FAQ автоответов
- Сбор заявки: имя → телефон → объект → услуга
- Обучение: непопадания → привязка к правилам
- Команды админа: /stats, /list, /find, /unknowns, /rules

## Переменные окружения
- BOT_TOKEN — токен MAX-бота
- WEBHOOK_SECRET — секрет вебхука
- ADMIN_IDS — ID админов через запятую

## Запуск
Bothost разворачивает автоматически по main.py
